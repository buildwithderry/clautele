# Dokumentasi Clautele (struktur PARA)

Dokumentasi diorganisasi dengan PARA (Tiago Forte, *Building a Second Brain*), diurutkan menurut **seberapa
actionable**, bukan jenis isinya.

| Folder | Isi | Aturan |
|---|---|---|
| `0 Inbox/` | Catatan mentah yang belum dipilah | Kosongkan saat review mingguan |
| `1 Projects/` | Upaya dengan hasil akhir jelas | Selesai → pindahkan foldernya utuh ke `4 Archives/` |
| `2 Areas/` | Tanggung jawab berkelanjutan yang punya standar | Tidak punya tanggal selesai |
| `3 Resources/` | Referensi yang mungkin berguna | Catatan hasil distilasi (kutipan verbatim + sorotan berlapis) |
| `4 Archives/` | Yang sudah tidak aktif | Tidak dihapus, hanya disimpan |

Pertanyaan saat menaruh catatan: proyek mana yang paling butuh ini? Kalau tidak ada → area? → resource? → arsip.

## Format catatan resource (Progressive Summarization)
Layer 1 = kutipan verbatim dari sumber, Layer 2 = **tebal**, Layer 3 = ==highlight==, Layer 4 = ringkasan
eksekutif. Tafsiran Claude dipisah di baris "Catatan Claude" dan bukan isi sumber.
